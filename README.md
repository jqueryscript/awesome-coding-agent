## What Is an AI Coding Agent

An AI coding agent accepts a development task, reads the relevant codebase, and takes action through file edits, command execution, tests, or debugging. The list includes terminal agents, agentic IDEs, autonomous software engineers, and browser or desktop tools that perform this work directly.

Code completion extensions, prompt collections, skills, SDKs, general agent frameworks, session managers, and orchestration tools are outside this list's scope.

## How Projects Qualify

A project must meet all of these requirements when it is added:

- It has an official, public GitHub repository with at least 500 stars.
- It acts directly on software development work by reading a repository and editing code, running commands, testing, or debugging.
- It is an independent product, not a prompt pack, plugin collection, SDK, general framework, session manager, or orchestration layer.
- It is not archived, a mirror, or a minimally changed fork of another listed project.
- Its description explains a concrete capability and can be verified from the project's own documentation.

Open-source, source-available, and closed-source agents with official public repositories may qualify. The license label describes the repository's current licensing status and does not imply that the connected model or hosted service is free.

Star counts are a popularity signal, not a quality score. Inclusion remains curated under the principles of the [Awesome Manifesto](https://github.com/sindresorhus/awesome/blob/main/awesome.md).
